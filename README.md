# ヘリウム大型風船・必要個数計算ツール

体重を入力するだけで、中性浮力に必要な大型ヘリウム風船（1800L）の個数を計算できるシンプルなWebツールです。

## 概要
このツールは、以下の条件に基づいて「人が浮くために必要な風船の個数」を理論的に算出します。

風船体積：**1800L（1.8 m³）**

風船自重：**3 g（0.003 kg）/個**

安全装備：**+0.5 kg**

標準大気（空気密度・ヘリウム密度）を使用

## 機能
### 基本機能

* 体重を入力するだけで即時計算

* 必要最小個数（切り上げ）を表示

* 自動計算ON/OFF切り替え

### 詳細表示（KPI）

* 風船1個あたりの正味揚力

* 対象の実効質量

* 合計揚力

* 余剰（安全マージン）

### カスタマイズ機能

**詳細パラメータを変更可能：**

* 風船体積（m³）

* 風船自重（kg/個）

* 空気密度（kg/m³）

* ヘリウム密度（kg/m³）

* 安全装備重量（kg）

## 計算式
**風船1個あたりの揚力**

`L1 = (ρ_air - ρ_He) × V_balloon - m_envelope`

**実効質量**

`m_eff = (体重 + 安全装備) × (1 - ρ_air / 1000)`

**必要個数**

`N = ceil(m_eff / L1)`

## 使い方

1. 「あなたの体重 (kg)」を入力

2. 必要に応じて詳細パラメータを調整

3. 自動的に結果が表示される（または手動更新）

## 対応環境

* PC / スマートフォン対応（レスポンシブデザイン）

* モダンブラウザ（Chrome / Safari / Edge など）

## ⚠️ 注意事項

* 本ツールは理論計算のみを目的としています

* 実際に人を浮かせる行為は非常に危険です

* 安全性・法規・環境条件などは考慮されていません

そのため、実用目的での使用は絶対に推奨しません
